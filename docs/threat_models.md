# Threat Models & Detection Methodologies: AEGIS Platform

This document specifies the 7 cyber threat categories analyzed by the AEGIS passive detection engine in unidirectional network monitoring environments.

All detection models operate strictly on passively observed packet headers, transport-layer framing, and temporal flow statistics. Zero packet injection, active handshakes, or payload decryption are used.

---

## 1. Volumetric & Protocol DDoS

- **Threat Description**: Distributed denial of service attempts aimed at overwhelming enclave servers or critical infrastructure endpoints.
- **Specialized Attack Subtypes**:
  1. **TCP SYN Floods**: Mass transmission of TCP SYN packets with no subsequent ACKs (`syn_ack_ratio > 10.0`), exhausting kernel TCP connection state tables.
  2. **High-Rate UDP Floods**: Volumetric floods saturating network interfaces with high packet arrival rates (`udp_rate > 80.0` pkts/sec).
  3. **UDP Amplification & Reflection**: Exploitation of misconfigured third-party servers on known reflective UDP ports:
     - DNS (UDP 53)
     - NTP (UDP 123)
     - SSDP (UDP 1900)
     - Memcached (UDP 11211)
     - LDAP (UDP 389)
     - *Detection signature*: Byte amplification ratio $\frac{\text{response\_bytes}}{\text{request\_bytes}} > 10.0$ and substantial byte volume.
  4. **Spoofed-Source Flooding**: Volumetric floods where the attacker randomizes source IP addresses to evade rate-limiting.
     - *Detection signature*: High source-IP Shannon entropy ($H_{src} \ge 3.5$ bits) and low Herfindahl concentration ($< 0.35$) coupled with elevated packet arrival rates.
- **Explainable Evidence Output**:
  ```json
  {
    "attack_subtype": "SPOOFED_SOURCE_FLOOD",
    "syn_rate": 824.0,
    "source_ip_entropy": 3.82,
    "herfindahl_index": 0.08,
    "syn_ack_ratio": 45.2,
    "unique_sources": 142
  }
  ```

## 2. Botnet C2 Beaconing

- **Threat Description**: Periodic heartbeats or check-in polling loops generated by compromised internal hosts connecting to remote Command & Control (C2) servers (e.g. Cobalt Strike, Sliver, Trickbot, Emotet).
- **Passive Indicators**:
  - **Inter-Arrival Time (IAT) Sequence**: Timestamps of consecutive connections from a host to the same external destination.
  - **Coefficient of Variation ($CV = \sigma / \mu$)**: Dispersion metric where $CV < 0.25$ indicates strict, machine-generated periodicity.
  - **Lag-1 Autocorrelation**: High correlation ($> 0.60$) between successive time intervals.
  - **Destination Rarity**: Host contacts an external destination that is infrequent or novel across the broader enclave baseline.
  - **Jitter Tolerance**: The algorithm accounts for configured implant jitter (e.g. $\pm 20\%$) while detecting bounded interval distributions.
- **Explainable Evidence Output**:
  ```json
  {
    "mean_inter_arrival_sec": 60.12,
    "std_inter_arrival_sec": 3.42,
    "coefficient_of_variation": 0.0569,
    "autocorrelation": 0.88,
    "periodicity_score": 0.94,
    "connection_count": 8,
    "destination_rarity": true
  }
  ```

## 3. DGA (Domain Generation Algorithm) Detection

- **Threat Description**: Algorithmic generation of pseudo-random domain names used by malware for resilient C2 rendezvous, circumventing static domain blacklists.
- **Passive Indicators**:
  - **High Shannon Entropy**: Elevated character entropy ($> 3.6$ bits/char) indicating high randomness.
  - **Lexical Structural Anomalies**: High digit ratio ($> 0.30$), low vowel ratio ($< 0.18$), and long consonant clusters (e.g. `x7k29a8d91b4mz09.biz`).
  - **Supervised Random Forest Classifier**: Evaluates multi-dimensional lexical n-gram and character distributions to output class probabilities.
- **Explainable Evidence Output**:
  ```json
  {
    "domain": "x7k29a8d91b4mz09.biz",
    "domain_entropy": 3.8842,
    "domain_length": 20,
    "digit_ratio": 0.4737,
    "vowel_ratio": 0.1053,
    "ml_probability": 0.9820
  }
  ```

## 4. DNS Tunnelling & Covert Channels

- **Threat Description**: Covert data exfiltration and bidirectional command encapsulation hidden within DNS request/response payloads (e.g. Iodine, DNScapy, Cobalt Strike DNS listeners).
- **Passive Indicators**:
  - **Subdomain Length & Entropy**: Large payload chunking into subdomain labels ($> 24$ characters) with high Shannon entropy ($> 3.75$ bits/char).
  - **Rolling Record-Type Distribution**: Sliding-window tracking of query types under an apex domain. Abnormal concentrations of TXT queries ($> 40\%$) or NULL queries ($> 10\%$) signal covert channel encapsulation.
  - **Apex Query Rate & Cardinality**: Abnormally high query frequencies ($> 8.0$ queries/sec) directed at an apex with numerous distinct pseudo-random subdomains.
- **Explainable Evidence Output**:
  ```json
  {
    "apex_domain": "exfil-tunnel.org",
    "subdomain": "a8f93e2b109c4d87e65fa31298c",
    "subdomain_length": 27,
    "subdomain_entropy": 4.1250,
    "txt_record_ratio": 0.65,
    "null_record_ratio": 0.15,
    "rolling_query_count": 48
  }
  ```

## 5. Encrypted Traffic Threats (TLS / QUIC)

- **Strict Guarantee**: ZERO PAYLOAD DECRYPTION.
- **Threat Description**: C2 communication and malicious activity tunneled over standard encrypted protocols (HTTPS / TLS 1.3 / HTTP/3 over QUIC).
- **Passive Indicators**:
  - **JA3 / JA4 Fingerprinting**: Unencrypted Client Hello cryptographic negotiation strings matched against cataloged malware profiles (Cobalt Strike, Metasploit, AsyncRAT).
  - **SNI Absence or Mismatch**: TLS sessions over port 443 lacking Server Name Indication or presenting direct IP targets.
  - **Sequence of Packet Lengths and Times (SPLT)**: Low variance and characteristic small packet sizes ($50\text{--}250$ bytes) indicating command polling rather than interactive web browsing.
  - **QUIC Framing Inspection (RFC 9000)**: Passive extraction of Long vs. Short headers, Initial/Handshake packet counts, and connection ID lengths over UDP port 443.
- **Explainable Evidence Output**:
  ```json
  {
    "suspicious_ja3_match": true,
    "ja3_hash": "e7d705a3286e19ea42f587b344ee6865",
    "ja4_fingerprint": "t13d1516h2_8daaf6152771_e8f1e7e78f70",
    "is_quic": false,
    "splt_mean_length": 142.5,
    "splt_length_variance": 18.2,
    "outbound_inbound_ratio": 12.8,
    "zero_decryption_verified": true
  }
  ```

## 6. Reconnaissance & Network Probing

- **Threat Description**: Initial adversary reconnaissance attempting to discover active hosts and open service ports across the monitored subnet.
- **Attack Subtypes**:
  - **Horizontal Scans**: Single host scanning a single port across dozens of distinct destination IPs in a short window.
  - **Vertical Scans**: Single host scanning dozens of distinct destination ports on a single IP target.
  - **SYN-Only Probes**: Connections consisting solely of SYN packets without subsequent application data transfer (`is_syn_only == True`, `duration < 0.5`s).
- **Explainable Evidence Output**:
  ```json
  {
    "scan_type": "HORIZONTAL_SWEEP",
    "unique_destination_hosts": 38,
    "unique_destination_ports": 1,
    "connections_per_second": 24.5,
    "destination_entropy": 4.82,
    "syn_only_ratio": 0.95
  }
  ```

## 7. Data Exfiltration

- **Threat Description**: Unauthorized transfer of sensitive data, database archives, or classified documents across monitored enclave boundaries.
- **Passive Indicators**:
  - **Severe Directional Asymmetry**: Outbound-to-inbound byte ratio exceeding $6.0:1$.
  - **High Sustained Outbound Throughput**: Outbound transfer rate exceeding $2.0$ MB/s in a single session.
  - **Unsupervised Anomaly Model**: Isolation Forest model scoring on flow byte volume and duration.
- **Explainable Evidence Output**:
  ```json
  {
    "outbound_bytes": 35000000,
    "inbound_bytes": 1024,
    "outbound_inbound_ratio": 3417.9,
    "outbound_rate_bytes_per_sec": 8235000.0,
    "isolation_forest_anomaly": true
  }
  ```

## 8. Threat Fusion & Composite Classification

Individual detector findings are synthesized by the **Threat Fusion Engine (`app/fusion/threat_fusion.py`)**:

### Multi-Vector Correlated Threats
When multiple distinct detectors fire for the same endpoints within a 25-second correlation window, composite alerts are produced with elevated confidence:
- `SUSPICIOUS_ENCRYPTED_TRAFFIC` + `DATA_EXFILTRATION` $\rightarrow$ `POSSIBLE_ENCRYPTED_EXFILTRATION` (Confidence: 0.95, Severity: CRITICAL)
- `C2_BEACONING` + `DNS_TUNNEL` $\rightarrow$ `SUSPICIOUS_C2_OVER_DNS` (Confidence: 0.95, Severity: CRITICAL)
- `RECON_SCAN` + `DDOS_ATTACK` $\rightarrow$ `PROBE_BEFORE_ATTACK` (Confidence: 0.90, Severity: HIGH)

### Unambiguous Fallback Classifications
- **`UNKNOWN_ANOMALY`**: Generated when ML anomaly models (e.g. Isolation Forest) or multivariate flow anomalies flag a session as statistically deviant, but no deterministic rule or signature matches. Rather than discarding or silently misclassifying the session, AEGIS presents it as an `UNKNOWN_ANOMALY` for analyst triage.
- **`INSUFFICIENT_EVIDENCE`**: Assigned when an alert candidate is generated but the session lacks minimum flow duration ($< 1.0$s) or minimum packet threshold ($< 4$ packets) necessary for statistical significance, preventing spurious low-evidence alarms.
